
# Author's Views

To assert, these views are my own and are not known to be affiliated with an organisaation I am attached to.

I have inserted this document here to at least express my own views as a way to highlight certain decisions regarding my discouragement and usage of particular software and services.

For some background, I started a similar project a while ago as I was teaching undergraduates, however I never got around to completely constructing a full resource (and still working on this and many others) that would be satisfactory. However, as of 2026, I felt like a major feat had been achieved and that I was able to provide a resource that makes learning to program accessible.

**However**, in the same year, software development and engineering has turned into large-scale plagiarism operation (lack of a better phrase). This kind of operation has substantially damaged trust in software and people.

It should be very simple to say and act with the following in mind:

* Don't steal
* Don't exploit others
* Ask for consent
* Don't spy on someone
* Try to help people
* Make the planet better

However, particular organisations around the world have shown a lack of interest in adhering to the above. This unfortunately has left myself in a predicament where I will reject or no longer recommend particular organisations or have a note associated with a rationale behind a change in my views.

In addition, I encourage anyone reading this book, to read it and work on the exercises without the aid of an LLM.

It would be my judgement, that if you are using an LLM to either:

* Summarise or Explain the text for you
* Generate code to solve a problem
* Utilise any of these resources in any way

Would be an affront to myself and one where you are insincere around your own learning, work, and others.
