# Introduction to Web Development

Within this chapter we will be examining web development. Using our skills that we have worked on with JavaScript, we will be integrating them with other web-development technologies such as HTML and CSS.

## Topics

The main take-away from the chapter is that you should understand the topic areas and apply skills within the following.

* HTML Markup and displaying HTML web pages
* Browsers and Document Object Model
* Defining pages and elements, structuring content
* Cascading Style Sheets (CSS), how they are used to decorate your web pages
* CSS Selectors and Querying Styles
* CSS Media Queries and Transitions
* Integrating JavaScript into web pages for event handling
