# Terminology

Below are a list of terms and a brief description.

| Term                    |                                                                |
| :----                   |                                                                |
| Text Editor | A program used to edit documents on your device, usually for the purpose writing programs |  
| Shell | Typically referred to as a command line interface - bash, zsh, powershell, fish, etc |
| Git | A program that is used for version control |
| Virtual Machine | A machine typically implemented in software that can execute instructions |
| Source Code | A file or set of file that contains code relating to a programming language |
| Software | A file which holds instructions that your operating system and computer can understand and execute |
