# Libraries and Node Modules

While we have been developing applications and depending on reusable code. We now start exploring developing our own modules/libraries within the JavaScript ecosystem.

There are different views/constructions of libraries that exist, we could simply write reusable components within a single `.js` file and distribute that or we could structure it using multiple files and provide an interface for it.

In this chapter we will go over the following topic areas.

* Creating Modules and Organising Code
* Modules and Module Scope
* Distribution and Inclusion

There are a variety of ways to construct your codebase but we will go through the process of constructing it and fitting within the node package model.
